# 《都市建设模拟：山水之间》游戏策划案（GDD v2 · 深化版）

> 竖屏手机城市建造模拟 · 对标端游《城市：天际线》(Cities: Skylines) 的核心系统与经营深度
> 设计目标：单局 40～80 小时；每个阶段解锁全新机制，玩法不重复；存档/命名/沙盒等端游基础体验完整。

---

## 0. 产品定位

- **一句话**：从山水间的一座村庄，经营成一座有产业、有交通、有市井生活的活都市。
- **对标**：《城市：天际线》的「分区生长 + 基础设施供给 + 交通拥堵 + 产业链 + 财政循环」骨架，简化到竖屏单手可玩。
- **差异点**：竖屏报纸/手账美术风 + 伪 3D 微立体建筑 + 山水地形（河流/湖泊/山丘）带来的用地约束。

## 1. 开始界面与存档系统（端游基础，最高优先）

### 1.1 主菜单（重构）

```
┌─────────────────────────────┐
│  都市建设模拟：山水之间        │
│  （刊头：晨光市城建日报）      │
├─────────────────────────────┤
│  [ 继续游戏 ]   ← 读最近存档   │
│  [ 新 游 戏 ]   ← 进入建城流程 │
│  [ 存档管理 ]   ← 3 个槽位管理  │
│  [ 沙盒模式 ]   ← 无限资金全解锁 │
│  [ 帮助/关于 ]                │
└─────────────────────────────┘
```

### 1.2 新游戏流程（三步）

1. **给城市命名**：输入框（默认「晨光市」，可改，6 字内）。城市名贯穿全局：顶栏、月报、简报刊头、成就文案。
2. **选地图种子**：随机摇号（显示种子数字）+ 手动输入；不同种子生成不同地形（河流走向、湖泊、山丘、大道骨架）。
3. **选难度**：
   - 轻松：收入 +20%、维护费 -20%、事件少
   - 标准：默认
   - 困难：收入 -20%、维护费 +30%、事件频率 ×2

### 1.3 存档系统

- **3 个存档槽**，每槽显示：城市名、人口、资金、游戏内日期、游玩时长、截图缩略。
- **自动存档**：每 30 游戏日自动覆盖当前槽。
- **手动存档**：暂停菜单「存档/读档/返回主菜单」。
- **存档内容**：完整序列化世界（地形/道路/分区/建筑/服务设施）+ 经济状态（资金/人口/满意度/税率/政策/贷款/成就/事件计时）+ 城市名 + 种子。
- **技术**：JSON 序列化到应用私有目录 `files/save_slot_N.json`；首次启动无存档则显示空槽。

## 2. 渲染与视觉（立体感专项）

### 2.1 建筑伪 3D（本次重点强化）

- 建筑 = 顶面（提亮 1.15）+ 侧面（压暗 0.60）+ 统一朝向的投影，营造"微立体"。
- **高度分级**：住宅 L1/L2/L3 → 矮楼/多层/高层；商业、工业、公共建筑各有高度。
- **窗格点阵**：侧立面按格点窗户，高层窗更密；夜晚（若做昼夜）窗户点亮。
- **生长动画**：新建建筑从 30% 弹跳到 100%（已实现，保留并加强回弹）。
- **阴影统一方向**：全部投影朝右下，强化立体感和太阳方向感。
- **高级建筑（后期）**：地标有独立外形（塔、穹顶、体育场）。

### 2.2 地形与装饰

- 山水元素：河流动态波纹、湖泊、山丘等高线、林地树冠（已有，加深层次）。
- 道路层级视觉：泥土路/道路/大道/高架快速路，宽度与中线颜色区分。
- 覆盖热力图：七种视图（电力/供水/垃圾/医疗/教育/消防/交通），半透明叠色。

## 3. 核心循环（深化）

```
建城命名 → 修路网 → 划分区 → 通电通水 → 城市生长 → 收税维持财政
   ↑                                    ↓
   └── 交通治堵 / 产业升级 / 教育医疗 / 环境治理 / 事件应对 ←┘
```

**财政是永恒的约束**：维护费随城市规模线性上涨，逼玩家不断扩税基、优化布局，端游的"破产焦虑"贯穿全程。

## 4. 分区与 RCI 需求（深化）

### 4.1 分区类型

| 分区 | 细分 | 解锁 | 特点 |
|---|---|---|---|
| 住宅 | 低密度 / 高密度 | 高密度在「城区」解锁 | 高密度人口更多、需教育+医疗支撑 |
| 商业 | 一般商业 / 大型商业 | 大型在「集镇」解锁 | 大型需要交通便利 + 高满意度 |
| 工业 | 基础工业 / 农业 / 制造业 / 高科技 | 逐级解锁 | 见产业链 |

### 4.2 RCI 需求算法（现有 + 细化）

- 住宅需求 = 岗位缺口（商业+工业岗位 − 人口）
- 商业需求 = 人口消费能力 − 商业容量（受教育人口权重更高）
- 工业需求 = 外部订单 + 商业供货缺口 − 工业容量
- **需求饱和惩罚**：过度划区导致需求崩盘（端游经典），需控制节奏。

## 5. 基础设施（已有 + 深化）

### 5.1 电力（已实现，深化供需）

- 电站：风电场（清洁、不稳定）→ 太阳能（清洁）→ 燃煤电厂（高污染、稳定）→ 核电站（后期，大覆盖、高维护、极低污染）。
- **电力盈余率**：供电容量 / 需求，<100% 则随机停电（区域断电，产业停摆）。鼓励留 20% 冗余。

### 5.2 供水（已实现）

- 水塔/水泵站，覆盖半径；缺水则人口停滞 + 满意度降。

### 5.3 垃圾（已实现）

- 垃圾场覆盖；堆积则满意度降 + 健康风险。

### 5.4 医疗（已实现，深化）

- 诊所 → 医院；覆盖率决定健康值，健康值影响满意度与寿命（见市民）。

### 5.5 消防与安全（已实现）

- 消防站覆盖；火灾烧毁建筑（已有）。

### 5.6 教育（深化为三层）

- 小学（学校）→ 中学 → 大学。教育覆盖 → 受教育人口累积 → 驱动产业升级。

---

## 6. 交通系统（端游灵魂，第三批核心）

### 6.1 道路分级

| 道路 | 解锁 | 容量 | 费用 | 噪音 |
|---|---|---|---|---|
| 泥土路 | 开局 | 低 | 免费 | 低 |
| 道路 | 开局 | 中 | 8/格 | 低 |
| 大道 | 开局 | 高 | 20/格 | 中 |
| 高架快速路 | 城区 | 极高 | 40/格 | 高 |

### 6.2 拥堵模型

- 每条路统计"流量/容量"。拥堵路段：
  - 货车进出受阻 → 商业/工业效率下降（收入打折）
  - 周边噪音 → 住宅满意度下降
- **拥堵热力图**：红（堵死）/黄（拥挤）/绿（通畅）。

### 6.3 公共交通

- 公交站（覆盖半径 6，缓解拥堵 + 满意度），地铁站（半径 10，城区解锁，大幅缓解）。
- 线路按里程碑解锁；玩家需在住宅-商业-工业之间布站。

---

## 7. 产业链与工业分层（第四批核心）

| 工业 | 解锁 | 污染 | 收入 | 前置条件 |
|---|---|---|---|---|
| 基础工业 | 开局 | 高 | 低 | 无 |
| 农业 | 小镇 | 低 | 中 | 需沿河/平原 |
| 制造业 | 集镇 | 中 | 中高 | 需中学教育人口 |
| 高科技 | 城区 | 无 | 高 | 需大学教育人口 + 高满意度 |

- **供需链**：工业供商业、商业供住宅、住宅供劳动力；任一环断裂，整体经济受损。
- 高科技是"终极形态"，需要教育 + 环境 + 交通多系统共同达标——这就是几十小时的长线目标。

---

## 8. 教育分层与就业

- 教育覆盖 → 每日转化受教育人口（慢变量）。
- 受教育比例 gating：商业 L3 升级、制造业/高科技工业、满意度上限。
- 数据面板显示"受教育人口占比"曲线。

---

## 9. 市民模拟与满意度（第五批）

- 人口统计：年龄分布、就业率、教育水平、平均健康、平均寿命。
- **满意度 = f(就业率, 教育, 医疗, 环境, 交通, 税率, 娱乐, 安全)**。
- 数据面板给"满意度根因"：六维雷达 + 每一项的拉低因素，玩家据此对症治理。
- 满意度决定：人口迁入速度、建筑升级速度、税收上限。

---

## 10. 环境系统（第五批）

- **空气污染**：工业/燃煤电厂扩散，邻格住宅满意度↓、健康↓。
- **噪音污染**：大道/高架周边住宅满意度↓。
- **水污染**：工业邻河排污 → 下游满意度↓。
- **地价**：绿化/滨水/教育抬升，污染/噪音拉低；地价决定建筑升级上限。
- 三种污染 + 地价，共 4 张热力图。

---

## 11. 财政、预算与贸易

### 11.1 税收（已实现 RCI 三税率）

### 11.2 分项预算（新增）

- 每类服务（电力/供水/垃圾/医疗/教育/消防/交通）独立预算滑块 50%~150%。
- 预算高 → 覆盖范围与效率提升、维护费涨；预算低 → 相反。
- 端游"省钱 vs 保民生"的经典权衡。

### 11.3 贸易与外部连接

- 地图边缘有"外部连接点"（沿大道）。
- 工业产出可出口换钱；缺货可进口（付钱）。
- 城市等级解锁更多连接点。

---

## 12. 政策（深化为分区政策）

- **全局政策**（已有）：减税/增税/绿化/营商/民生。
- **分区政策**（新增，城区解锁）：
  - 工业区：禁止高污染 / 鼓励高科技（税收优惠）
  - 住宅区：禁高密度 / 公共出行免费
  - 商业区：夜间经济（消费+、满意度−）

---

## 13. 随机事件与灾害（防重复核心）

### 13.1 随机事件（每日小概率，权重轮盘）

| 事件 | 影响 | 应对 |
|---|---|---|
| 火灾（已有） | 烧楼 | 消防覆盖 |
| 停电 | 随机区域断电 | 电力冗余 |
| 水管爆裂 | 缺水区满意度↓ | 供水覆盖 |
| 经济危机 | 收入 −30%（15天） | 降税/贷款 |
| 投资热潮 | 商业需求暴涨（20天） | 抢建商业 |
| 流感 | 健康↓满意度↓ | 医疗覆盖 |
| 罢工 | 工业停产（10天） | 高满意度 |
| 节日 | 消费+满意度+ | 无 |
| 名人到访 | 满意度+地价+ | 无 |
| 楼市泡沫 | 住宅需求暴涨后回落 | 把握节奏 |

### 13.2 自然灾害（困难模式/后期）

- 洪水（沿河）、地震、龙卷风、陨石——大范围破坏，考验冗余与恢复力。

## 14. 任务、成就与生涯

- **市政任务**：同时 1~2 个限时目标（人口/资金/覆盖率/满意度），完成刷新，给短中期节奏。
- **成就**：已实现 10 项，扩充到 25 项（覆盖各系统）。
- **市长生涯模式**：目标导向（如"20 年建成大都会"），通关评分。

---

## 15. 昼夜、天气与季节

- **昼夜**：夜间电力需求 +20%（冗余压力），建筑窗亮，画面变暗。
- **天气**：晴天/雨/雾，影响满意度与旅游。
- **季节**：春夏秋冬，冬季供暖（满意度−）、夏季旅游（收入+），一年 4 季每季 30 天。

## 17. 进度曲线（40~80 小时）

| 阶段 | 时长 | 人口 | 解锁 | 核心玩法 |
|---|---|---|---|---|
| 村庄 | 0~1.5h | 0~150 | 基础工业/电力/供水 | 学会循环 |
| 小镇 | 1.5~5h | 150~500 | 消防/中学/垃圾/公交/农业 | 覆盖布局 |
| 集镇 | 5~12h | 500~1500 | 制造业/医院/任务/事件/大型商业 | 产业链+教育 |
| 城区 | 12~30h | 1500~4000 | 地铁/大学/高科技/高架/分区政策 | 交通治堵+产业升级 |
| 都市 | 30~55h | 4000~10000 | 核电站/地标/贸易/季节 | 精细化运营 |
| 大都会 | 55~80h+ | 10000+ | 全地标/全成就/灾害 | 冲击完美 |

## 18. 数值总表（要点）

- 人均日税 0.04 万（10% 基准）；基础补贴 2.5 万/日；道路维护 0.006/格·日。
- 税率 5~15%，超 10% 每点满意度 −1.2。
- 缺电/缺水各 −15 满意上限，垃圾 −10；缺电产业收入最低 40%。
- 贷款：借 800 万、日还 30、冷却 90。
- 成就 25 项，总奖金约 5 万（早期关键现金流）。
