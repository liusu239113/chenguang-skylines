# 《都市建设模拟：山水之间》重构策划案（合理性专项）

> 本方案针对当前版本的"摆设感"问题做系统性重构。
> 核心原则：**每个系统都必须有真实因果链** —— 电从电线杆来、水从水管来、人从迁入来、钱从税收来、车有目的地、灯是夜晚亮的。
> 没有合理来源的东西一律不做成摆设。

## 1. 人口系统（重做）

**合理性**：人不是凭空出现的。住宅楼建成 → 空置 → 家庭迁入 → 入住 → 成为人口。

- **迁入规则**：每栋住宅按等级有容量（L1=12 人 / L2=36 / L3=90，沿用）。住宅建成后开始迁入，迁入速度 = 基础值 × 满意度系数 × 就业机会系数。
- **人口 = Σ 所有住宅入住人数**（不再是全局缓动变量）。
- **就业**：人口需要岗位。岗位 = 商业容量 + 工业容量。就业率 = 岗位/劳动力。就业率低 → 迁入放缓、满意度降。
- **UI**：点住宅楼显示「入住 8/12」；顶栏人口实时 = 总入住。
- **修复点**：住宅一建成人口就开始涨，不会再"有小区却 0 人口"。

## 2. 经济系统（明确现金流）

**钱的来源**（每笔都可见）：
1. **住宅人头税**：每人每天 0.04 万 × 住宅税率
2. **商业税**：商铺月收入 × 商业税率（商铺收入来自接待人口）
3. **工业税**：工厂产出 × 工业税率（产出出口或供商业）
4. **基础补贴**：2.5 万/天（新手期兜底）

**钱的去向**：
1. 道路维护费（每格/日）
2. 设施维护费（每栋/日）
3. 贷款还款

**财政面板**：实时显示「今日收入明细 / 支出明细」，点开能看每一笔。解决"钱从哪来"。

## 3. 交通系统（彻底重做，最高优先级）

### 3.1 道路与车道
- **单车道道路**：一条双向共用车道（车靠右，两向错开偏移）。
- **双车道大道**：两条方向相反的车道，各走各的（右行）。
- 车辆**不再走格子中心线**，而是走各自车道的偏移位置（右行偏移 ±cell×0.15）。

### 3.2 车辆目的地（不再乱走）
- **通勤车**：住宅 → 商业/工业（上班），下班返回。
- **货车**：工业 → 商业（供货）、工业 → 城外（出口）。
- 车沿路网做**带目的地的路径**（A* / 沿大道骨架 + 支路贪心），不是随机转向。

### 3.3 红绿灯（真实生效）
- 路口设信号灯，**周期相位切换**（南北绿→东西绿）。
- 红灯：车辆在路口停止线前**排队停车**；绿灯：依次起步通过。
- 车流可视化：拥堵热力图反映等灯长度。

### 3.4 防穿模
- 同车道**前后车保持最小车距**，前车减速则后车跟随减速。
- 路口排队车辆一辆接一辆，不重叠。

### 3.5 对外连接
- 地图边缘（大道端点）设**城外入口**。
- 货车从城外入口进出：出口工业品换钱，进口补给（可选）。
- 这是"跟外面通车"的合理性来源。

## 4. 供电 / 供水（合理性重做）

**核心规则：电和水必须"有载体"才能到户。**

### 4.1 电力
- 电站本身产生电力。
- **电线杆沿道路自动铺设**：只要道路连通到电站，沿路的建筑就能通电（道路 = 电网）。
- 未连到电站的孤立道路/建筑 = 断电（红标）。
- 发电量 vs 总用电量：不够就轮流停电（区域断电）。

### 4.2 供水
- 水泵/水塔产水，**水管沿道路铺设**，同理沿路网供水。
- 道路未连通水源 = 缺水区（红标）。

### 4.3 视觉
- 道路两侧画**电线杆**（小点/短线），大道可加路灯柱。
- 夜晚电线杆/路灯亮起。

## 5. 昼夜循环 + 天空 + 天气 + 路灯

### 5.1 昼夜（天空盒）
- 一天一个循环：**清晨 → 白昼 → 黄昏 → 夜晚**，天空颜色平滑渐变（暖黄→蓝→橙红→深蓝）。
- 夜晚地图整体压暗，**建筑窗户点亮、路灯点亮、车辆开灯**。

### 5.2 天气
- 晴 / 雨 / 雾轮换，影响：雨天道路湿滑（车流略慢）、满意度微降；雾天可见度降。

### 5.3 路灯
- 道路自带路灯，夜晚沿路亮灯（光晕点），黄昏时自动开启。

## 6. 建筑立体感（重做）

- 建筑改为**真正的多面体**：顶面 + 左右两个侧面 + 统一光源投影，屋檐/层高线/屋顶瓦片细节。
- 高度按类型分级，高层建筑有玻璃幕墙反光（夜晚亮窗）。
- 目标：站在地图上看是"一栋楼"，不是"盖了个方块"。

## 7. 服务设施（每类都有因果）

| 设施 | 解决什么 | 缺失后果 |
|---|---|---|
| 电站 | 供电 | 断电 → 停产停生活 |
| 水塔/水泵 | 供水 | 缺水 → 人口停滞 |
| 垃圾场 | 收垃圾 | 堆积 → 满意度↓健康↓ |
| 诊所/医院 | 医疗 | 生病 → 满意度↓ |
| 学校/中学/大学 | 教育 | 产业无法升级 |
| 消防站 | 灭火 | 火灾烧楼 |
| 公园/广场 | 休闲 | 满意度低 |

每个设施都对应一个"缺了会出问题的状态"，不是装饰。

## 8. 事件系统（由状态触发，不是乱随）

- 事件**必须由城市状态触发**：
  - 停电 = 缺电时触发
  - 水管爆裂 = 供水老化/超负荷
  - 火灾 = 无消防覆盖的建筑
  - 流感 = 医疗覆盖不足
  - 罢工 = 满意度长期偏低
  - 投资热潮 = 经济上行期随机
- 每个事件有明确诱因、影响、应对手段。

## 9. 交通枢纽（后期解锁）

| 设施 | 解锁 | 作用 |
|---|---|---|
| 公交站 | 小镇(150人) | 覆盖通勤、降拥堵 |
| 火车站 | 城区(1500人) | 连接城外、大运量 |
| 机场 | 都市(4000人) | 旅游收入 + 满意度 |
| 港口（滨水） | 城区 | 沿河货运 |

枢纽需配合对外连接才有效（火车站连城外铁路线）。

## 10. 分阶段实施路线（按合理性优先级）

| 阶段 | 内容 | 说明 |
|---|---|---|
| A | 人口 + 经济可视化 | 先让"人从哪来、钱从哪来"成立 |
| B | 供电供水沿路网 + 电线杆水管 | 基础设施有物理载体 |
| C | 车辆重做（车道/目的地/红绿灯/防穿模） | 交通合理性 |
| D | 昼夜/天空/路灯 | 氛围 |
| E | 建筑立体感重做 | 视觉 |
| F | 对外连接 + 公交/火车/机场 | 后期深度 |
| G | 事件由状态触发 | 合理性收尾 |
