## 环境坑
- 全局 git 配置了 http.proxy/https.proxy = http://127.0.0.1:65532，但该端口无进程监听，导致 clone 报 "Failed to connect to github.com port 443 via 127.0.0.1"。
- 解决办法：直连可用，用 `GIT_CONFIG_COUNT=2 GIT_CONFIG_KEY_0=http.proxy GIT_CONFIG_VALUE_0= GIT_CONFIG_KEY_1=https.proxy GIT_CONFIG_VALUE_1= git <cmd>` 临时清空代理即可。
- 全局存在 url.insteadof 规则，把 https://github.com/ 重写为带 token 的 URL，因此 git 操作能免密；仓库 .git/config 里存的是干净 URL（无明文 token）。
