# 都市建设模拟：山水之间

手机版城市建造模拟，玩法对标《都市天际线》核心循环。当前仓库以 **Android 原生版（Kotlin + Jetpack Compose）** 为准。

## 核心循环

```
修路 → 划分区 → 通电通水 → 分区自动长楼 → 收税维持财政
  ↑                                         ↓
  └── 交通治堵 / 教育医疗 / 政策法令 / 产业升级 ←┘
```

对照《详细拆解文档参考》落地的系统：

- **RCI 需求**：岗位缺口、消费能力、税率、过度划区、政策倍率共同驱动生长
- **政策法令**：启用后持续改税收、需求、污染、拥堵、火灾、维护费，到期才失效
- **基础设施**：电/水沿路网传播，容量不足会停电停水并拖垮产业收入
- **升级门槛**：建筑需邻路、通电通水、地价达标、存在足够天数才会升级
- **财政**：人头税 + 产业税 + 贸易 − 道路/设施维护 − 贷款；可破产告急
- **存档**：3 个槽位，新游戏立刻写入；暂停菜单保存后主菜单能看到城市名/人口/日期
- **交通**：右行车道、目的地寻路、红绿灯排队、雨天减速、夜间车灯
- **建筑**：顶面 + 左右侧面 + 统一投影 + 窗格点阵，夜晚亮窗

## Android

`android/` 是可安装的 Gradle 工程（minSdk 26 / targetSdk 35）。

- 地图：自定义 `MapRenderView`（Canvas 2.5D）
- UI：报纸风 Compose（主菜单 / 地图 / 晨光简报）
- 字体：站酷快乐体
- 音效：SoundPool（建造 / 点击 / 拆除 / 晋级 / 月报 / 政策 / 存档）

推送到 `main` 会触发 `.github/workflows/android.yml` 产出 debug APK，并尝试发布 GitHub Release。

## 目录
